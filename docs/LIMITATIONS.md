# 当前方法和实现边界

1. 此方法直接蒸馏最终答案坐标，尚不能据此宣称定位漂移的推理过程被纠正。较早共识框也可能与后续推理内容冲突。
2. 十个框来自同一推理轨迹，相关性较强；稳定不等于正确。稳定度门控是预设经验规则，不使用 GT 选教师。
3. 坐标交叉熵仅在门控开启时添加，按完整批次 128 条平均；没有对推理 token 直接添加蒸馏目标。
4. 当前实现未排除触顶/未自然闭合的 rollout。它们若通过共识门控，仍可参与蒸馏；排除方案仅被提出，尚未修改此快照。
5. 读框的跨请求前缀缓存关闭。Qwen3.5 含混合注意力状态；不能把理论前缀处理量节约直接当作实际训练加速。
6. 训练 schema 答案采样 temperature 0.7，中途和评估读框贪心。GRPO 使用共同 full-vocabulary surrogate，未对受约束生成分布作 grammar-normalized 校正。
7. 纯 GRPO 不生成中途读框，因此其 rollout 记录不能离线计算时间线共识准确率。
8. 只用最终 checkpoint64 评估原 val500；本快照尚无完成后的新方法结果。单 seed 探索不能支持论文级稳健性结论。
9. 用户提到的 68.6% 来自训练 1994 条的基础时间线投票；原 val500 的基础最终/投票准确率分别为 54.8%/58.0%，应区分数据队列。

此快照保留现有算法，不包含讨论中的触顶过滤、缓存复用或新的训练中验证改动。
